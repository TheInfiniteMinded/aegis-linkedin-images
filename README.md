# Aegis LinkedIn images

The post images for the Aegis Technologies Inc. LinkedIn campaigns (Q4 2026), public so Buffer can
import them by link. One folder per product, named by post date and account:

- `aeroassure/` — Aegis AeroAssure®
- `autoassure/` — Aegis AutoAssure
- `medassure/` — Aegis MedAssure™
- `skyassure/` — Aegis SkyAssure
- `youtube-shorts/<week>/` — the week's YouTube Shorts (MP4), one file per Short, for Buffer to
  publish on the Aegis Technologies Inc. channel. Source: Aegis-Outreach `video/shorts/`; these
  can be deleted once the week has published.

Source: each product's `LinkedIn_Q4_2026/images/` in the Aegis-Outreach repository, copied by
`schedule/build_buffer.py --stage`. Change the images there, not here.
